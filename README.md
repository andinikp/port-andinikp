### 1. 🧶 Rajut.in — Sistem Stok Bahan & Keuangan
Aplikasi manajemen operasional bisnis kerajinan rajut untuk memecahkan masalah selisih pencatatan stok dan mempermudah perhitungan laba bersih.
* **Fitur Utama:**
  - **Dashboard Ringkasan Bisnis:** Total pendapatan, laba bersih setelah biaya produksi, total pesanan, pelanggan aktif, dan indikator *Stok Hampir Habis* secara real-time.
  - **Manajemen Pesanan Siap & Custom:** Pelacakan pesanan siap kirim vs pesanan khusus dengan timeline produksi.
  - **Kontrol Bahan & Keuangan:** Peringatan otomatis stok minimum, rekapitulasi arus kas masuk/keluar, serta grafik produk terlaris.
* **Teknologi:** PHP, JavaScript, Tailwind CSS, Relational Database.
* **Demo URL:** [https://rajutin-seven.vercel.app/](https://rajutin-seven.vercel.app/)

### 2. 📱 Sistem Absensi QR Code Mahasiswa
Aplikasi presensi modern untuk menggantikan absensi manual yang rawan antrean dan sulit direkapitulasi.
* **Fitur Utama:**
  - **Pemindaian QR Cepat:** Pencatatan otomatis status kehadiran (Hadir, Sakit, Izin, Alpa) tanpa kontak fisik.
  - **Manajemen Data Master:** CRUD terstruktur untuk Data Mahasiswa, Program Studi, dan Angkatan.
  - **Monitoring & Laporan:** Rekapitulasi absensi harian, bulanan, dan ekspor laporan per kelas/angkatan.
* **Teknologi:** Fullstack Web Application, QR Code Scanner Engine, Cloud Deployment.
* **Demo URL:** [https://sistem-absensi-qr.vercel.app/](https://sistem-absensi-qr.vercel.app/)

## 🔄 Alur Kerja Pengembangan (Development Process)

```
[01 Analyze & ERD] ──► [02 UI Wireframe] ──► [03 Fullstack Dev] ──► [04 Validation & Deploy]
  Riset Kebutuhan        Desain Figma           Koding Logika          Uji Akurasi & Rilis
  & Struktur Data        & Tata Letak           & Integrasi DB         ke Vercel / Server
```

1. **01. Analyze & Database ERD:** Memetakan alur bisnis, aturan validasi, hak akses pengguna, dan normalisasi relasi database.
2. **02. UI Wireframe & Layout:** Merancang prototipe antarmuka di Figma agar intuitif, ergonomis, dan nyaman bagi pengguna operasional.
3. **03. Fullstack Development:** Mengimplementasikan kode backend transaksi, validasi input form, serta frontend yang responsif di berbagai ukuran layar.
4. **04. Validation & Deploy:** Melakukan pengetesan perhitungan data, fungsionalitas tombol, responsivitas lintas browser, dan deployment ke cloud.

## 💻 Cara Menjalankan Secara Lokal

### Menggunakan Laragon / XAMPP:
1. Pastikan folder proyek berada di direktori web server (misalnya: `d:/laragon/www/porto` atau `C:/xampp/htdocs/porto`).
2. Jalankan Apache dari panel Laragon / XAMPP.
3. Buka browser dan akses alamat:
   ```
   http://localhost/porto
   ```

### Menggunakan Live Server (VS Code / Antigravity IDE):
1. Buka folder proyek di editor.
2. Klik kanan pada `index.html` dan pilih **"Open with Live Server"**.
